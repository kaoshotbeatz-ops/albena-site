# Pair Your Hub

## Connect your Albena Hub

1. Power on your Albena Hub and complete the initial setup on the Hub itself
2. During setup, the Hub displays an 8-character code on its screen (like `AB12-CD34`)
3. Go to [account.albena.ai](https://account.albena.ai) and sign in
4. Click **+ Add Hub** and enter the 8-character code
5. Click **Pair** — you're done!

## Important notes

- The pairing code **expires in 10 minutes**. If it expires, restart the Hub's setup to generate a new code.
- You can pair multiple Hubs to the same account.
- Each Hub is owned by one account but can be shared with household members.
